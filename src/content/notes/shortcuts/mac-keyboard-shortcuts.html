01

System, Power & Sleep

Shortcuts for controlling the machine itself — waking, sleeping, restarting, and force-quitting frozen apps.

⌘+Space
Open Spotlight Search
Opens the system-wide search overlay to find apps, files, documents, and perform quick calculations or conversions.
⌘+⌥+⌫
Force Quit dialog
Opens the Force Quit Applications window, letting you select and terminate a frozen or unresponsive app.
⌘+⌥+⌃+⌫
Force quit the frontmost app
Immediately force-quits the currently active application without opening the Force Quit dialog first.
⌘+⌃+Power
Force restart
Immediately restarts the Mac without saving open documents — use only when the system is completely unresponsive.
⌃+Power
Shutdown / Restart / Sleep dialog
Opens a dialog offering Restart, Sleep, and Shut Down options.
⌘+⌥+Power
Put the display to sleep
Immediately sleeps the screen while keeping the Mac itself running.
⌘+⌃+Q
Lock the screen instantly
Locks the Mac and returns to the login screen, requiring a password (or Touch ID) to resume.
⌘+⌃+Eject / Power
Log out of the current user
Prompts to log out of the current macOS user account.
02

Windows, Apps & Mission Control

Switching between apps, arranging windows, and navigating between desktops/Spaces.

⌘+Tab
Switch between open apps
Hold Command and press Tab repeatedly to cycle through the app switcher; release to jump to the highlighted app.
⌘+⇧+Tab
Switch apps in reverse order
Cycles backward through the app switcher instead of forward.
⌘+`
Cycle windows within the same app
Switches between multiple open windows belonging to the currently active application.
⌘+W
Close the current window
Closes the frontmost window without quitting the application itself.
⌘+⌥+W
Close all windows of the app
Closes every open window belonging to the frontmost application in one action.
⌘+Q
Quit the current app
Fully quits the frontmost application, closing all its windows and ending its process.
⌘+M
Minimize the front window
Sends the active window to the Dock.
⌘+⌥+M
Minimize all windows of the app
Minimizes every window belonging to the frontmost application at once.
Control+↑
Open Mission Control
Shows all open windows and Spaces (virtual desktops) at once, arranged for quick navigation.
Control+← / →
Move between Spaces (desktops)
Switches to the desktop space immediately to the left or right of the current one.
Control+↓
App Exposé
Shows all windows of the currently active application, spread out for easy selection.
fn+F / Globe+F
Toggle full screen
Expands the active window to fill the entire display (equivalent to the green traffic-light button).
03

Finder & File Management

Navigating, organizing, and acting on files and folders in Finder.

⌘+N
New Finder window
Opens a fresh Finder window at your default location.
⌘+⇧+N
New folder
Creates a new folder in the current Finder location, ready for renaming.
⌘+←
Delete an item / Move to Trash
Moves the selected file or folder to the Trash.
⌘+⇧+←
Empty the Trash
Permanently deletes everything currently in the Trash after a confirmation prompt.
Space
Quick Look
Previews the selected file — image, PDF, document, or video — in a pop-up window without opening its app.
⌘+I
Get Info
Opens the info panel for the selected item, showing size, kind, permissions, and tags.
⌘+D
Duplicate the selected item
Creates an identical copy of the selected file or folder in the same location.
⌘+C then ⌘+⌥+V
Copy and paste, moving the original
Copies a file, then pastes it as a move rather than a duplicate — equivalent to cut-and-paste for files.
⌘+↑
Go up one folder level
Navigates to the parent folder of the currently open Finder location.
⌘+⇧+G
Go to Folder
Opens a text field to jump directly to a folder by typing its path.
⌘+⇧+.
Show hidden files
Toggles visibility of hidden files and folders (those starting with a dot) in Finder.
⌘+R (on a selected item)
Reveal original of an alias
Jumps to and highlights the original file that a selected alias/shortcut points to.
04

Text Editing & Navigation

Selecting, moving through, and formatting text in any app — these largely mirror standard system-wide text shortcuts.

⌘+A
Select all
Selects every item in the current document, list, or window.
⌘+C / X / V
Copy, Cut, Paste
The standard clipboard trio for duplicating, removing, and inserting selected content.
⌘+⇧+V
Paste and Match Style
Pastes clipboard text while stripping its original formatting, adopting the destination's style instead.
⌘+Z / ⌘+⇧+Z
Undo / Redo
Steps backward or forward through your recent edit history.
⌥+← / →
Jump one word left/right
Moves the cursor a full word at a time instead of one character.
⌘+← / →
Jump to start/end of line
Moves the cursor to the beginning or end of the current line.
⌘+↑ / ↓
Jump to start/end of document
Moves the cursor to the very top or bottom of the document.
⇧+arrow keys
Extend text selection
Combine Shift with any of the movement shortcuts above to select text as the cursor moves.
⌥+⌫
Delete the previous word
Deletes backward one full word at a time instead of one character.
⌘+B / I / U
Bold, Italic, Underline
Applies the corresponding text formatting to the current selection in apps that support rich text.
⌘+F
Find
Opens a search field to find text within the current document or page.
⌘+G / ⌘+⇧+G
Find next / previous
Jumps to the next or previous match of the current Find search.
05

Screenshots & Screen Recording

Capturing exactly what's on screen — full display, a selected region, a specific window, or video.

⌘+⇧+3
Capture the entire screen
Takes a screenshot of the whole display and saves it to the Desktop (or clipboard, if combined with Control).
⌘+⇧+4
Capture a selected region
Turns the cursor into a crosshair to drag-select a specific area of the screen to capture.
⌘+⇧+4, then Space
Capture a single window
After triggering region capture, pressing Space switches to window mode — click any window to capture just it, complete with its drop shadow.
⌘+⇧+5
Open the Screenshot toolbar
Opens a persistent on-screen toolbar with options for full-screen, window, and selection screenshots, plus screen recording.
Add Control to any capture shortcut
Copy to clipboard instead of saving
Holding Control while taking any screenshot copies the image directly to the clipboard rather than saving a file to the Desktop.
06

Safari & Browsing

Tab and window management for Safari — most of these also work in Chrome and other major browsers on macOS.

⌘+T
Open a new tab
Opens a fresh browser tab in the current window.
⌘+W
Close the current tab
Closes just the active tab, leaving the rest of the window open.
⌘+⇧+T
Reopen the last closed tab
Restores the most recently closed tab, including its scroll position — press repeatedly to restore several in a row.
Control+Tab / ⌘+⌥+→
Switch to the next tab
Moves focus to the tab immediately to the right of the current one.
⌘+L
Jump to the address bar
Highlights the URL bar so you can immediately type a new address or search term.
⌘+R
Reload the page
Refreshes the current webpage.
⌘+[ / ]
Go back / forward
Navigates to the previous or next page in the tab's browsing history.
⌘++ / -
Zoom in / out
Increases or decreases the page's zoom level for easier reading.
⌘+D
Bookmark the current page
Adds the active page to your bookmarks.
07

Spotlight, Siri & System Search

Fast ways to find files, launch apps, and get quick answers without touching the mouse.

⌘+Space
Spotlight Search
The universal search overlay — launch apps, find files, do quick math, check the weather, or convert units, all from one field.
⌘+⌥+Space
Open Finder search window
Opens a dedicated Finder window pre-set to search mode, useful for browsing multiple search results at once.
Hold fn or ⌘+Space (config.)
Activate Siri
Triggers Siri voice assistant, depending on your configured shortcut in System Settings.
08

Accessibility

Built-in shortcuts that make the display and interface easier to see, hear, and navigate.

⌘+⌥+8
Toggle Zoom
Turns screen magnification on or off, letting you enlarge whatever the cursor is near.
⌘+⌥+= / -
Zoom in / out
Once Zoom is enabled, increases or decreases the magnification level.
⌘+⌥+F5
Open Accessibility Shortcuts panel
Opens a quick-access panel for toggling VoiceOver, Zoom, and other accessibility features.
⌘+F5
Toggle VoiceOver
Turns Apple's built-in screen reader on or off, narrating what's on screen.
09

Special Characters & Emoji

Inserting symbols, accented letters, and emoji without switching keyboard layouts.

⌘+Control+Space
Open the Emoji & Symbols viewer
Opens a searchable palette of emoji and special characters that can be inserted into any text field.
Hold a letter key
Accented character picker
Press and hold most letter keys to reveal a popover of accented variants (e.g. holding "e" offers é, è, ê, ë).
⌥+2 / ⌥+R / etc.
Common Option-key symbols
The Option key combined with letter/number keys types symbols like ™ (Option+2), ® (Option+R), € (Option+Shift+2), and £ (Option+3) — layout dependent.
Note on scope: These are the standard system-level and Finder/Safari shortcuts built into macOS. App-specific shortcuts (in apps like Pages, Photos, Mail, or third-party software) vary by app — check each app's Help menu, which lists every shortcut it supports, or the Keyboard Shortcuts pane in System Settings to view or customize system-wide bindings.
